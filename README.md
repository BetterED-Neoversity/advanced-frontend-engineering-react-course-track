# Заняття 4 — Побічні ефекти

Етапи життєвого циклу компонента: монтування, оновлення, розмонтування

## Побічні ефекти з `useEffect`

- `https://swapi.info/api/people/1`
- Запит при монтуванні компонента
- Залежності ефекта
- Синтаксис `async/await`
- Суворий режим і подвійне монтування (`Timer`)
- Очищення ефектів (`Timer`)
- Створюємо сайдбар (`Sidebar`)

## Робота з LocalStorage

- Зберігаємо стан сайдбара (`Sidebar`)
- Запис через ефект
- Читання через `useState(callback)`

## Стартові файли у проєкті

- `src/components/Timer.tsx` — запустити інтервал при монтуванні, очистити при розмонтуванні
- `src/components/Sidebar.tsx` — додати обробник `keydown` при монтуванні, закривати по `Escape`, очистити при розмонтуванні

## Послідовність заняття

1. Розібрати етапи життєвого циклу компонента
2. Додати `useEffect` з запитом до `https://swapi.info/api/people/1` при монтуванні
3. Показати залежності ефекта
4. Перейти до `Timer` — запустити інтервал, показати подвійне монтування в Strict Mode, очистити інтервал
5. Перейти до `Sidebar` — додати обробник `keydown`, показати подвійний слухач в Strict Mode, очистити при розмонтуванні
6. Зберегти стан сайдбара в `localStorage` через ефект
7. Читати початковий стан з `localStorage` через `useState(callback)`
