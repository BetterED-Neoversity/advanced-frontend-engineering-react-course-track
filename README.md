## Послідовність заняття

1. Розбір `main.tsx` — що таке JSX і як працює рендер
2. JSX вирази у розмітці та атрибутах, правило спільного батька, фрагменти
3. Умовний рендер — поле `available` у даних котів
4. Створити компонент `CatCard` з пропсами — показати повторне використання з різними котами
5. Створити компонент `CatList` — рендер колекції з `cats.json` через `map` та `key`
6. Підключити CSS-модулі для стилізації `CatCard` та `CatList`
