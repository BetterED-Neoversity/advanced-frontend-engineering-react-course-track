# Advanced Front-End Engineering with React

Шаблонний репозиторій для викладача дисципліни **Advanced Front-End Engineering with React** (магістратура, BetterED Neoversity).

## Як почати

Створи власний репозиторій з цього шаблону через кнопку **Use this template** на GitHub та клонуй його локально:

```bash
git clone <url-твого-репозиторію>
```

Перед кожним заняттям переходь на відповідну гілку:

```bash
git checkout module-01/lesson-01
```

Відкрий `README.md` — там план заняття та послідовність роботи. Встанови залежності та запусти проєкт:

```bash
npm install
npm run dev
```
