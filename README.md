# Заняття 3 — Форми та HTTP-запити

## Форми

- Форма як компонент (`OrderForm`)
- Обробка форми з `onSubmit`
- Типізація події
- Отримання значень через `FormData`
- Обробка форми з `Form Actions`
- Хук `useId`

> Нагадати що в LMS є повний матеріал по роботі з всіма елементами форми

## HTTP-запити

```text
https://hn.algolia.com/api/v1/search
```

- Форма пошуку `SearchForm`
- HTTP-запит при сабміті
- Збереження результату запита в стан
- Відображення даних
- Індикатор завантаження
- Обробка помилок
- Структура файлів та поділ відповідальності
- Змінні оточення та `.env`

## Стартові файли у проєкті

- `src/components/OrderForm.tsx` — форма замовлення, потребує обробника `onSubmit` та типізації події
- `src/components/SearchForm.tsx` — форма пошуку, потребує типізації пропсу `onSearch` та підключення обробника
- `src/components/ArticleList.tsx` — список результатів пошуку, потребує типізації пропсу `items`

## Послідовність заняття

1. Додати `onSubmit` до `OrderForm` — отримати значення через `FormData`
2. Показати `Form Actions` як альтернативу
3. Додати `useId` для зв'язку `label` та `input`
4. Перейти до `SearchForm` — підключити HTTP-запит при сабміті
5. Зберегти результат у стан, відрендерити через `ArticleList`
6. Додати індикатор завантаження та обробку помилок
7. Винести логіку запиту в окремий сервісний файл
8. Показати змінні оточення через `.env`
